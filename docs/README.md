# FirstMate Gateway Documentation

This directory contains the approved project context that implementers and AI agents should treat as the source of truth.

Read in this order:

1. [`02-product-engineering-spec.md`](./02-product-engineering-spec.md) — what the product must do and what is out of scope.
2. [`01-tech-stack-decisions.md`](./01-tech-stack-decisions.md) — accepted foundation and constraints.
3. [`03-technical-design.md`](./03-technical-design.md) — how the system should work.
4. [`04-implementation-plan.md`](./04-implementation-plan.md) — dependency-ordered implementation milestones and verification checkpoints.
5. [`00-concept.md`](./00-concept.md) — concise concept and original scope rationale.

The root [`AGENTS.md`](../AGENTS.md) contains execution rules for agents and contributors, including the currently authorized implementation milestone.

For operating an installed package, see the [operator guide](./operator-guide.md). It is operational documentation, not a replacement for the approved product and technical source-of-truth documents above.
